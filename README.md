# Sistema de Cadastro de Funcionários

Sistema CRUD desenvolvido em Python para gerenciamento de funcionários.

## Funcionalidades

- Cadastrar funcionário
- Listar funcionários
- Buscar funcionário
- Editar funcionário
- Remover funcionário
- Calcular média salarial
- Funcionário com maior salário

## Tecnologias

- Python 3

## Como executar

1. Clone o repositório
2. Execute o arquivo sistema_funcionarios.py
